## 5. Architectural Invariants & Limitations

1. **Design System Consistency**:
   - Palette: Warm Ivory `#F5F2ED`, Blackboard `#565656`, Oxblood `#76323F`, Tan `#C09F80`, Deep Charcoal `#1A1D20`.
   - Typography: Playfair Display (Headlines), Plus Jakarta Sans (Prose & UI), JetBrains Mono (Specs & Telemetry).
   - Geometry: Sharp unrounded corners (`rounded-none` / `0px`) throughout all components.
2. **Navigation Standard**:
   - Clean responsive top bar with slide-out drawer on mobile/tablet.
   - Elimination of the mobile sticky bottom bar to maximize viewable reading height and avoid OS gesture collisions.
3. **Known Limitations**:
   - Stitch prototypes are visual design artifacts; backend preservation, database migrations, and API integrations remain an engineering implementation responsibility to be verified by automated regression test suites.
   - Store digital downloads require active Supabase storage bucket configuration with corresponding signed token capabilities in production.
