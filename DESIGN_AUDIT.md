# SHIVSASTRA // DESIGN AUDIT & TOKENS (PHASE 0)
*Evaluation of Existing Visual Language & Specification of the Warm Editorial Luxury System*

---

## 1. Existing Design System Deficiencies

1. **Cold & Tech-Generic Palette**: The existing UI leaned heavily on dark blue/navy surfaces (`#0B1020`), slate borders, and electric indigo/violet highlights. This created a generic SaaS/AI-template aesthetic rather than an established technology brand.
2. **Typography Monoculture**: Heavy reliance on standard sans-serif system fonts created lack of hierarchy and editorial prestige.
3. **Table Cramping in Mobile Chat**: AI responses generated raw markdown tables and `<br>` tags that caused horizontal scrolling and broken characters on small viewports.
4. **Visual Over-crowding**: Dense technical jargon and lack of generous whitespace made scanning case studies difficult for non-technical founders.

---

## 2. The Approved Warm Editorial Luxury System

The Master Redesign shifts SHIVSASTRA to an authoritative, warm editorial visual identity:

### 2.1. Primary Color Tokens

| Token Name | Hex Code | Role in Design System | Application Rules |
|:---|:---:|:---|:---|
| **Grain** | `#D7CEC7` | Canvas Surfaces & Soft Background Tint | Used for card backgrounds, secondary containers, and soft canvas grounding. |
| **Blackboard** | `#565656` | Primary Editorial Text & Subheadings | Primary typography ink, subheadings, labels. Soft, readable, non-harsh contrast. |
| **Oxblood** | `#76323F` | Primary Actions & Brand Accents | Primary CTA buttons, active state indicators, hover highlights, links. |
| **Tan** | `#C09F80` | Subtle Hairline Borders & Dividers | Card borders, table dividers, decorative hairlines, badge outlines. |
| **Warm Ivory** | `#F5F2ED` | Primary Background Canvas | Main site surface, high-contrast readable reading plane. |
| **Dark Charcoal** | `#1A1D20` | Contrast Footers & Code Containers | Code blocks, contrast terminal panels, and footer grounding. |

### 2.2. Strict Color Prohibitions
- **NO Bright Orange** (`#FF5722`, `#FF9800`)
- **NO Violet / Neon Purple** (`#8B5CF6`, `#A855F7`)
- **NO Electric Blue** (`#00E5FF`, `#2563EB`, `#3B82F6`)
- **NO Harsh Pitch Black** (`#000000` text on `#FFFFFF` backgrounds)

---

## 3. Typography Architecture

- **Editorial Headings**: `Playfair Display` (Serif, font-weights 400, 600, 700). Evokes editorial gravitas, prestige, and high-trust technology publishing.
- **Body & Product UI**: `Inter` / `Manrope` (Clean geometric Sans-Serif, font-weights 400, 500, 600). Maximum legibility across dense metrics, specs, and mobile viewports.
- **Code & System Telemetry**: `JetBrains Mono` / `SFMono-Regular` (Monospace). System badges, release codes, prices, and terminal displays.

---

## 4. Brand Mark: The Trishul-Inspired Geometric 'S'

- **Geometric Abstraction**: A minimalist, high-precision monogram derived from three clean vertical prongs meeting in a refined central curve ('S').
- **Strict Prohibition**: Completely avoid overt deity illustrations, religious iconography, or heavy temple graphics. Maintain absolute technology elegance and architectural simplicity.
